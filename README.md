# 30 Days of Vanilla JavaScript

This repository contains 30 small projects I built while learning JavaScript through practice.

I followed the **Wes Bos JavaScript30 course** and used it as a reference while building everything on my own.

Course link:
https://courses.wesbos.com/

---

## Why I did this

I realized that just watching tutorials wasn’t helping me actually *think in JavaScript*.
So I decided to build things - small, focused projects — every day.

These projects helped me understand:

* how to break a problem into steps
* how to use JavaScript to control the UI
* how to debug when things don’t work (which happened a lot)

More than anything, this challenge helped me build the intuition of:

> “If I want *this* behavior, how do I actually code it?”

---

## What’s inside

30 mini projects using:

* HTML
* CSS
* Vanilla JavaScript (no frameworks)

Each project focuses on one concept or pattern.
